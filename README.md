# Web programiranje – Laboratorijske vježbe
Repozitorij sadrži laboratorijske vježbe iz kolegija **Web programiranje**.
## Stečene vještine
- Izrada responzivnih web stranica korištenjem **HTML-a** i **CSS-a**
- Stilizacija stranica pomoću **Flexboxa** i **Grid sustava**
- Dodavanje interaktivnosti pomoću **JavaScripta**
- Korištenje **PHP-a** za izradu dinamičkih stranica i obradu formi
- Rad s bazom podataka
- Povezivanje web aplikacije s bazom putem PHP-a (korištenje SQL upita)
- Osnove validacije podataka na klijentskoj i serverskoj strani
